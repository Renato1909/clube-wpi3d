# Clube WPI3D

Plataforma web do Clube WPI3D, desenvolvida para apresentar
produtos de impressão 3D e, futuramente, permitir solicitações
de orçamento, gerenciamento de pedidos, upload de arquivos e
pagamentos.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS

## Funcionalidades atuais

- Página inicial responsiva
- Identidade visual do Clube WPI3D
- Apresentação de produtos
- Galeria de trabalhos realizados

## Funcionalidades planejadas

- Solicitação de orçamento
- Cadastro e login de clientes
- Upload de imagens e modelos 3D
- Painel administrativo
- Acompanhamento de pedidos
- Pagamentos via Pix e cartão
